# GoodCopBadCopUnity AI Context

Shared project rules for AI-assisted work in this Unity repo.

This folder contains common guidance only. Tool-specific context, indexes, and generated snapshots belong in tool-specific subfolders and should not be treated as shared rules.

## Start Here

1. Read `AGENTS.md`.
2. Read this `README.md`.
3. Read `SESSION_START.md`.
4. For architecture-sensitive work, read `ARCHITECTURE.md`.
5. For process, tests, verification, or commit naming, read `WORKFLOW.md`.
6. Inspect actual source files before making claims or edits.

## Shared File Index

- `SESSION_START.md` - compact shared context packet for new AI sessions.
- `ARCHITECTURE.md` - shared architecture direction for new significant features.
- `WORKFLOW.md` - shared work cycle, testing rules, verification, and commit naming.

## Operating Rules

- Do not load every AI doc by default.
- Keep shared docs focused on durable project rules.
- Do not put tool-specific indexes or generated snapshots into shared rules.
- Update shared docs only when a convention changes, not for every feature.
